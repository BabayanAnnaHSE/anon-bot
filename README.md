# AnonChatHSE_bot

Анон-бот - бот для анонимной отправки сообщений в групповые чаты в Telegram

## Возможности:
- анонимная отправки сообщений в групповые чаты
- отправка любых файлов и вложений
- возможность отложенной отправки
- история запросов

## Стек
- FastAPI
- Aiogram
- SQLite
- SQLAlchemy
- APScheduler
