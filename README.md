# Anon Bot

Telegram-бот для анонимной отправки сообщений в групповые чаты с поддержкой вложений и отложенной отправки.

## Описание проекта

Anon-Bot позволяет участникам Telegram-групп отправлять анонимные сообщения в группы, где зарегистрирован бот.

Проект разработан в рамках индивидуального проекта НИУ ВШЭ.

### Основные возможности

* регистрация групп через команду `/register`;
* анонимная отправка текстовых сообщений;
* отправка фотографий;
* отправка видео;
* отправка документов;
* отложенная отправка сообщений;
* автоматическая обработка очереди отложенных сообщений;
* проверка участия пользователя в группе через Telegram API.

---

## Архитектура

Проект состоит из трёх компонентов:

### Backend

FastAPI

Отвечает за:

* работу с базой данных;
* регистрацию групп;
* хранение истории сообщений;
* получение очереди отложенных сообщений;
* изменение статуса сообщений.

### Frontend

Telegram Bot (Aiogram 3)

Отвечает за:

* взаимодействие с пользователем;
* выбор группы;
* ввод текста;
* прикрепление файлов;
* выбор времени отправки;
* подтверждение отправки.

### Database

SQLite + SQLAlchemy

Используется для хранения:

* зарегистрированных групп;
* истории анонимных сообщений;
* информации о вложениях;
* времени отправки;
* статуса сообщений.


```text

```


## Сценарий использования

1. Добавить бота в Telegram-группу.
2. Выполнить команду:

```text
/register
```

3. Открыть личный чат с ботом.
4. Выполнить:

```text
/ start
```

5. Выбрать группу.
6. Ввести текст сообщения.
7. При необходимости прикрепить файл.
8. Выбрать время отправки.
9. Подтвердить отправку.

---

## Особенности безопасности

Пользователь может отправлять сообщения только в те группы, участником которых он является.

Проверка выполняется через метод Telegram API:

```python
bot.get_chat_member(...)
```

Это исключает возможность отправки сообщений в чужие группы.
